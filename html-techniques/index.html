1. Semantic HTML

  • ใช้ landmark ได้แก่ header, nav, main, article, section, aside, footer แทนการใช้ div ล้วน (MDN)
  • มี main แค่หน้าละหนึ่งอัน ใช้ article กับเนื้อหาที่อ่านแยกได้ และใช้ section ที่มีหัวข้อกำกับ
  • หัวข้อต้องเรียงตามลำดับชั้นโดยไม่ข้ามระดับ และไม่ใช้แท็กหัวข้อแค่เพื่อขยายตัวอักษร (MDN headings)

2. Accessibility

  • ใส่ skip link เป็นจุดโฟกัสแรกของหน้า (web.dev focus)
  • ถ้ามี nav หลายอัน ให้ใส่ aria-label แยกแต่ละอัน (web.dev navigation)
  • ห้ามใช้ tabindex ค่าบวก และห้ามลบ outline โดยไม่มีสไตล์โฟกัสอื่นมาแทน
  • ใช้ ARIA เท่าที่จำเป็น ถ้าแท็ก HTML ทำหน้าที่นั้นได้อยู่แล้วก็ไม่ต้องใช้ (web.dev ARIA)
  • คอนทราสต์ตัวอักษรอย่างน้อย 4.5:1 และตัวใหญ่อย่างน้อย 3:1 (WCAG 1.4.3)
  • ห่อแอนิเมชันด้วย prefers-reduced-motion

3. จัดระเบียบ CSS

  • CUBE CSS: ตั้งค่า global ก่อน แล้วค่อยต่อด้วย Composition, Utility, Block, Exception
  • ใช้ custom properties เป็น design token
  • ใช้ @layer คุมลำดับความสำคัญของสไตล์ (MDN @layer)
  • ใช้ logical properties เช่น margin-inline และ padding-block (MDN)

4. Responsive

  • Intrinsic layout แบบ Every Layout ประกอบ primitive เล็ก ๆ เข้าด้วยกัน ลดการพึ่ง breakpoint
  • ใช้ clamp() ทำตัวอักษรให้ไหลตามจอ ตามแนวทาง Utopia และต้องทดสอบตอนผู้ใช้ซูมด้วย
  • ใช้ @container เมื่อคอมโพเนนต์ต้องเปลี่ยนตามขนาดกล่อง (MDN container queries)
  • Flex สำหรับจัดแกนเดียว Grid สำหรับสองแกน

5. Performance

  • ใส่ critical CSS แบบ inline ใน head (web.dev)
  • preload เฉพาะฟอนต์ที่ใช้จริง และตั้ง font-display: swap หรือ optional (web.dev fonts)
  • รูป LCP ห้าม lazy-load และต้องอยู่ใน HTML ตั้งแต่แรก (web.dev LCP)
  • รูปที่อยู่ล่างหน้าใส่ loading="lazy" (web.dev)
  • ส่วนยาวที่ยังไม่เลื่อนถึงใช้ content-visibility: auto คู่กับ contain-intrinsic-size (web.dev)

6. เอกสารหลายตอน

  • สารบัญใช้ลิงก์ไปที่ id ของแต่ละหัวข้อ (CSS-Tricks)
  • ถ้ามีเฮดเดอร์ติดจอ ให้ตั้ง scroll-padding-top กันหัวข้อถูกบัง (CSS-Tricks)
  • ทำสไตล์สำหรับพิมพ์ด้วย @media print และ @page (MDN printing, CSS-Tricks @page)
  • รูปและกราฟใช้ figure คู่กับ figcaption (MDN)
  • ตารางใส่ caption (Heydon Pickering)
